Endpoints for receiving inbound payment provider events (Nomba) and managing outbound webhook destinations.

- `/inbound/nomba` — Public endpoint for Nomba to send events
- `/endpoints/*` — Manage your webhook destinations (requires `sk_` key)
- `/events/*` — View event history and delivery attempts (requires `sk_` key)
