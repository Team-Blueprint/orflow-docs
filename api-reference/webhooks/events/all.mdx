---
title: "List Webhook Events"
openapi: "GET /v1/webhooks/events/all"
---

List recent outbound webhook events triggered by the tenant's activity.

<CodeGroup>
```bash { title: "cURL" }
curl {{API_BASE_URL}}/v1/webhooks/events/all \
  -H "X-API-Key: sk_test_..." \
  -H "X-Project-ID: <project_id>"
```
</CodeGroup>

**Query Parameters:**

| Field | Type | Description |
|-------|------|-------------|
| `skip` | integer | Records to skip. Default: `0` |
| `limit` | integer | Max records. Default: `50` |

**Response:**

```json
[
  {
    "id": "3f7c1a2b-...",
    "event_type": "subscription.activated",
    "payload": { ... },
    "status": "delivered",
    "created_at": "2024-01-15T10:30:00Z"
  }
]
```

**Required Headers:**

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes (`sk_` key only) |
