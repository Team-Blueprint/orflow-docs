---
title: "List Webhook Endpoints"
openapi: "GET /v1/webhooks/endpoints/all"
---

List all registered webhook endpoints for this tenant.

<CodeGroup>
```bash { title: "cURL" }
curl {{API_BASE_URL}}/v1/webhooks/endpoints/all \
  -H "X-API-Key: sk_test_..." \
  -H "X-Project-ID: <project_id>"
```
</CodeGroup>

**Response:**

```json
[
  {
    "id": "3f7c1a2b-...",
    "url": "https://your-app.com/webhooks/orflow",
    "secret": "whsec_a1b2c3...",
    "description": "Production webhook handler",
    "is_active": true,
    "created_at": "2024-01-15T10:30:00Z"
  }
]
```

**Required Headers:**

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes (`sk_` key only) |
