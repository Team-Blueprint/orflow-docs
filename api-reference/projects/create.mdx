---
title: "Create Project"
openapi: "POST /v1/projects/create"
---

Create a new project within your tenant. Projects provide logical separation.

**Request Body:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | yes | Display name for the project |
| `description` | string | no | Description of the project |

**Example Request:**

```json
{
  "name": "Acme Corp Dashboard",
  "description": "Main dashboard project"
}
```

**Response:**

```json
{
  "id": "3f7c1a2b-...",
  "name": "Acme Corp Dashboard",
  "description": "Main dashboard project",
  "created_at": "2024-01-15T10:30:00Z"
}
```

**Required Headers:**

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes |
