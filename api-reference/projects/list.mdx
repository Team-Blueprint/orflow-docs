---
title: "List Projects"
openapi: "GET /v1/projects/list"
---

List all projects for the authenticated tenant.

**Response:**

```json
[
  {
    "id": "3f7c1a2b-...",
    "name": "Acme Corp Dashboard",
    "description": "Main dashboard project",
    "created_at": "2024-01-15T10:30:00Z"
  }
]
```

**Required Headers:**

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes |
