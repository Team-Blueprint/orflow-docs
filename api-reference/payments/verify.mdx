---
title: "Verify Payment"
openapi: "GET /v1/payments/{reference}/verify"
---

Verify payment status by calling the payment provider's verify transaction API.

**Path Parameters:**

| Field | Type | Description |
|-------|------|-------------|
| `reference` | string (UUID) | The order reference or transaction ID to verify |

**Response:**

```json
{
  "transaction_id": "3f7c1a2b-...",
  "status": "success",
  "provider_reference": "PRV-12345",
  "amount_minor": 10000,
  "failure_reason": null,
  "message": "Transaction verified successfully",
  "raw": { ... }
}
```

**Required Headers:**

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes |
