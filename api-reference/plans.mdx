Plans define how much and how often customers are charged. They support multiple billing intervals, trial periods, and installment options.

## Create a Plan

Define a new billing plan:

```bash
POST /v1/plans/create
```

**Request:**
```json
{
  "name": "Premium Plan",
  "description": "Access to advanced developer features",
  "amount": 10000,
  "currency": "NGN",
  "interval": "monthly",
  "interval_count": 1,
  "trial_period_days": 14,
  "installments_count": null
}
```

**Supported Intervals:**

| Interval | Description |
|----------|-------------|
| `daily` | Every N days |
| `weekly` | Every N weeks |
| `monthly` | Every N months |
| `yearly` | Every N years |

<Note>
Amount is in minor units (kobo for NGN, cents for USD). So 10000 = 100.00 NGN.
</Note>

<Tip>
Set `installments_count` to limit the number of billings (e.g., 12 for a yearly commitment billed monthly). Leave `null` for unlimited recurring.
</Tip>

## List Plans

Retrieve all plans with optional filtering:

```bash
GET /v1/plans/list?active_only=true&offset=0&limit=100
```

**Response:**
```json
[
  {
    "id": "uuid",
    "name": "Premium Plan",
    "description": "Access to advanced developer features",
    "amount": 10000,
    "currency": "NGN",
    "interval": "monthly",
    "interval_count": 1,
    "trial_period_days": 14,
    "installments_count": null,
    "status": "active",
    "created_at": "2024-01-15T10:30:00Z"
  }
]
```

## Get a Plan

Retrieve a single plan by ID:

```bash
GET /v1/plans/{plan_id}
```

## Update a Plan

Modify a plan's settings:

```bash
PATCH /v1/plans/{plan_id}/update
```

**Request:**
```json
{
  "name": "Updated Plan Name",
  "description": "Updated description",
  "trial_period_days": 7,
  "installments_count": 6
}
```

<Note>
Archived plans cannot be modified.
</Note>

## Archive a Plan

Prevent new subscriptions from using this plan. Active subscriptions continue unaffected:

```bash
POST /v1/plans/{plan_id}/archive
```

## Error Responses

| Status | Meaning |
|--------|---------|
| 200 | Success |
| 201 | Created |
| 400 | Validation error |
| 404 | Plan not found |
| 422 | Cannot modify archived plan |

## Required Headers

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes |
| `X-Project-ID` | Yes |
