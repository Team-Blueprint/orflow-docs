---
title: "Get Current Tenant"
openapi: "GET /v1/auth/me"
---

Return the profile of the currently authenticated tenant.

**Auth:** Requires JWT (from `Authorization: Bearer` header or `access_token` cookie).

**Response:**

```json
{
  "id": "3f7c1a2b-...",
  "name": "Your Name",
  "email": "you@example.com",
  "is_active": true,
  "created_at": "2024-01-15T10:30:00Z"
}
```
