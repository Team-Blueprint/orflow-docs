---
title: "Logout"
openapi: "POST /v1/auth/logout"
---

Clear all auth cookies to log out. Requires CSRF token header for cookie-authenticated requests.

**Headers:**

| Header | Required |
|--------|----------|
| `X-CSRF-Token` | Yes (when using cookie auth) |

**Response:**

```json
{
  "message": "Logged out"
}
```

**Notes:** No `X-API-Key` required.
