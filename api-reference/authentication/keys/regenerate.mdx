---
title: "Regenerate API Key"
openapi: "POST /v1/auth/keys/regenerate"
---

Replace an existing API key. The old key stops working immediately. No grace period.

<CodeGroup>
```bash { title: "cURL" }
curl -X POST {{API_BASE_URL}}/v1/auth/keys/regenerate \
  -H "Authorization: Bearer <dashboard_jwt_token>" \
  -H "X-CSRF-Token: <csrf_token>" \
  -H "Content-Type: application/json" \
  -d '{
    ...
  }'
```
</CodeGroup>

**Auth:** Requires JWT + CSRF token header.

**Request Body:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `key_type` | enum | yes | `pk_test`, `sk_test`, `pk_live`, or `sk_live` |

**Response:**

```json
{
  "key_type": "sk_test",
  "value": "sk_test_newKeyValue...",
  "active": true
}
```
