title: "Authentication API"
sidebarTitle: "Overview"
---

Endpoints for managing API keys for programmatic access to the Orflow API.

**Available endpoints:**
- `GET /v1/auth/keys/new` — View all four API key slots and their active status
- `POST /v1/auth/keys/create` — Generate a new key for an unused slot
- `POST /v1/auth/keys/regenerate` — Replace an existing key (old key stops working immediately)
- `POST /v1/auth/keys/revoke` — Soft-revoke a key slot

<Note>
These endpoints require JWT authentication (dashboard session). They are not accessible via API key.
</Note>
