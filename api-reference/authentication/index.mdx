sidebarTitle: "Overview"
---

API keys for programmatic access to the Orflow API are managed per-project from the **Dashboard → Project Settings**.

<Note>
API key management is handled entirely through the dashboard UI. Keys are scoped to individual projects — you must be a member of a project to view or manage its keys. There is no public API endpoint for managing keys.
</Note>
