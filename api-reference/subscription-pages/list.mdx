---
title: "List Subscription Pages"
openapi: "GET /v1/subscription-pages/list"
---

Returns all subscription pages for the current tenant and project, including plan name and project name.

<CodeGroup>
```bash { title: "cURL" }
curl {{API_BASE_URL}}/v1/subscription-pages/list \
  -H "X-API-Key: sk_test_..." \
  -H "X-Project-ID: <project_id>"
```
</CodeGroup>

**Query Parameters:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `offset` | integer | no | Number of records to skip (default: `0`) |
| `limit` | integer | no | Maximum records to return (default: `100`) |

**Response:**

```json
[
  {
    "id": "6a0b4d5e-...",
    "tenant_id": "7b1c5d6e-...",
    "project_id": "8c2d6e7f-...",
    "plan_id": "3f7c1a2b-...",
    "code": "abc123xy",
    "is_active": true,
    "is_test": true,
    "plan_name": "Pro Plan",
    "project_name": "Main Product",
    "url": "/subscribe/abc123xy",
    "created_at": "2024-01-15T10:30:00Z",
    "updated_at": "2024-01-15T10:30:00Z"
  }
]
```

**Required Headers:**

| Header | Value |
|--------|-------|
| `X-API-Key` | `sk_test_...` or `sk_live_...` |
| `X-Project-ID` | Your project UUID |
