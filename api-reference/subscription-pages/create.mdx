---
title: "Create Subscription Page"
openapi: "POST /v1/subscription-pages/create"
---

Create a new shareable subscription page linked to a plan. A unique short code is auto-generated for the page URL.

**Request Body:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `plan_id` | string (UUID) | yes | The plan to link this page to |

**Example Request:**

```json
{
  "plan_id": "3f7c1a2b-..."
}
```

**Response:**

```json
{
  "id": "6a0b4d5e-...",
  "tenant_id": "7b1c5d6e-...",
  "project_id": "8c2d6e7f-...",
  "plan_id": "3f7c1a2b-...",
  "code": "abc123xy",
  "is_active": true,
  "is_test": true,
  "created_at": "2024-01-15T10:30:00Z",
  "updated_at": "2024-01-15T10:30:00Z"
}
```

The `code` field is the short identifier used in the public checkout URL.

**Required Headers:**

| Header | Value |
|--------|-------|
| `X-API-Key` | `sk_test_...` or `sk_live_...` |
| `X-Project-ID` | Your project UUID |
