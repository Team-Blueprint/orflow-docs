---
title: "Get a Plan"
openapi: "GET /v1/plans/{plan_id}"
---

Retrieve a single plan by ID.

**Path Parameters:**

| Field | Type | Description |
|-------|------|-------------|
| `plan_id` | string (UUID) | Unique identifier of the plan |

**Response:**

```json
{
  "id": "3f7c1a2b-...",
  "name": "Premium Plan",
  "amount": 100.00,
  "currency": "NGN",
  "interval": "monthly",
  "interval_count": 1,
  "status": "active",
  "created_at": "2024-01-15T10:30:00Z"
}
```

**Required Headers:**

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes |
| `X-Project-ID` | Yes |
