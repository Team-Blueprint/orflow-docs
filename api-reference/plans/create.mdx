---
title: "Create Plan"
openapi: "POST /v1/plans/create"
---

Create a new billing plan. Amounts are in **major currency units** (e.g. `10.00` for ₦10).

<CodeGroup>
```bash { title: "cURL" }
curl -X POST {{API_BASE_URL}}/v1/plans/create \
  -H "X-API-Key: sk_test_..." \
  -H "X-Project-ID: <project_id>" \
  -H "Content-Type: application/json" \
  -d '{
    ...
  }'
```
</CodeGroup>

**Request Body:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | yes | Display name for the plan |
| `amount` | number (decimal) | yes | Price in major currency units (e.g. `29.99` for ₦29.99) |
| `currency` | string | yes | ISO currency code (e.g. `NGN`) |
| `interval` | enum | yes | Billing interval: `daily`, `weekly`, `monthly`, or `yearly` |
| `interval_count` | integer | no | Number of intervals between charges. Default: `1` |
| `trial_period_days` | integer | null | Free trial duration in days. `null` = no trial |
| `installments_count` | integer | null | Limit to N payments. `null` = unlimited recurring |

**Example Request:**

```json
{
  "name": "Premium Plan",
  "amount": 100.00,
  "currency": "NGN",
  "interval": "monthly",
  "interval_count": 1,
  "trial_period_days": 14,
  "installments_count": null
}
```

**Response:**

```json
{
  "id": "3f7c1a2b-...",
  "name": "Premium Plan",
  "amount": 100.00,
  "currency": "NGN",
  "interval": "monthly",
  "interval_count": 1,
  "trial_period_days": 14,
  "installments_count": null,
  "status": "active",
  "created_at": "2024-01-15T10:30:00Z"
}
```

**Required Headers:**

| Header | Value |
|--------|-------|
| `X-API-Key` | `sk_test_...` or `sk_live_...` |
| `X-Project-ID` | Your project UUID |
