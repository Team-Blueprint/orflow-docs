Reconciliation helps you identify and resolve discrepancies between Orflow's records and payment provider records.

## List Discrepancies

```bash
GET /v1/reconciliation/discrepancies?page=1&per_page=20&resolved=false&discrepancy_type=amount_mismatch&date_from=2024-01-01&date_to=2024-01-31
```

**Query Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `run_id` | UUID | Filter by reconciliation run |
| `tenant_id` | UUID | Filter by tenant (platform keys only) |
| `discrepancy_type` | Enum | `missing_in_orflow`, `missing_in_provider`, `amount_mismatch`, `status_mismatch` |
| `resolved` | Boolean | Filter by resolution status |
| `date_from` | ISO8601 | Filter by created date (from) |
| `date_to` | ISO8601 | Filter by created date (to) |
| `page` | Integer | Page number (default: 1) |
| `per_page` | Integer | Items per page (default: 20, max: 100) |

**Response:**
```json
{
  "items": [
    {
      "id": "uuid",
      "run_id": "uuid",
      "tenant_id": "uuid",
      "discrepancy_type": "amount_mismatch",
      "orflow_amount": 10000,
      "provider_amount": 9500,
      "currency": "NGN",
      "resolved": false,
      "created_at": "2024-01-15T10:30:00Z"
    }
  ],
  "total": 1,
  "page": 1,
  "per_page": 20
}
```

## Resolve a Discrepancy

Mark a discrepancy as resolved (requires platform-level `sk_` API key):

```bash
PATCH /v1/reconciliation/discrepancies/{discrepancy_id}/resolve
```

**Request:**
```json
{
  "resolution_note": "Provider fee of 500 NGN not accounted for in Orflow record"
}
```

<Note>
Only platform-level secret keys (`sk_test_...` or `sk_live_...` from platform admin) can resolve discrepancies.
</Note>

## Discrepancy Types

| Type | Description |
|------|-------------|
| `missing_in_orflow` | Transaction exists in provider but not in Orflow |
| `missing_in_provider` | Transaction exists in Orflow but not in provider |
| `amount_mismatch` | Amount differs between Orflow and provider |
| `status_mismatch` | Transaction status differs |

## Required Headers

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes (platform `sk_` key for resolve) |
