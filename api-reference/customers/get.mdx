---
title: "Get a Customer"
openapi: "GET /v1/customers/{customer_id}"
---

Retrieve a single customer by UUID.

<CodeGroup>
```bash { title: "cURL" }
curl {{API_BASE_URL}}/v1/customers/<customer_id> \
  -H "X-API-Key: sk_test_..." \
  -H "X-Project-ID: <project_id>"
```
</CodeGroup>

**Path Parameters:**

| Field | Type | Description |
|-------|------|-------------|
| `customer_id` | string (UUID) | Unique identifier of the customer |

**Response:**

```json
{
  "id": "3f7c1a2b-...",
  "email": "customer@example.com",
  "name": "John Doe",
  "external_id": "CUST-001",
  "created_at": "2024-01-15T10:30:00Z"
}
```

**Required Headers:**

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes |
