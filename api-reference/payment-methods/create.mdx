---
title: "Create Payment Method"
openapi: "POST /v1/payment-methods/create"
---

Register a tokenized payment method for a customer. The `provider_token` comes from your payment provider's SDK.

**Request Body:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `customer_id` | string (UUID) | yes | The customer to attach this payment method to |
| `type` | string | yes | Payment method type (e.g. `card`) |
| `provider_token` | string | yes | Token from the payment provider's SDK |
| `last_four` | string | no | Last 4 digits of the card |
| `expiry_month` | integer | no | Card expiry month (1-12) |
| `expiry_year` | integer | no | Card expiry year (e.g. `2028`) |
| `is_default` | boolean | no | Set as customer's default. Default: `false` |

**Example Request:**

```json
{
  "customer_id": "3f7c1a2b-...",
  "type": "card",
  "provider_token": "tok_visa_abc123",
  "last_four": "4242",
  "expiry_month": 12,
  "expiry_year": 2028,
  "is_default": true
}
```

**Response:**

```json
{
  "id": "7b1c5e6f-...",
  "customer_id": "3f7c1a2b-...",
  "type": "card",
  "last_four": "4242",
  "expiry_month": 12,
  "expiry_year": 2028,
  "is_default": true,
  "created_at": "2024-01-15T10:30:00Z"
}
```

**Required Headers:**

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes |
