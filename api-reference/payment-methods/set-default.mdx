---
title: "Set Default Payment Method"
openapi: "POST /v1/payment-methods/{payment_method_id}/set-default"
---

Mark a payment method as the default for its customer.

<CodeGroup>
```bash { title: "cURL" }
curl -X POST {{API_BASE_URL}}/v1/payment-methods/<payment_method_id>/set-default \
  -H "X-API-Key: sk_test_..." \
  -H "X-Project-ID: <project_id>" \
  -H "Content-Type: application/json" \
  -d '{
    ...
  }'
```
</CodeGroup>

**Path Parameters:**

| Field | Type | Description |
|-------|------|-------------|
| `payment_method_id` | string (UUID) | Unique identifier of the payment method |

**Response:**
Returns the `PaymentMethodRead` object with `is_default: true`.

**Required Headers:**

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes |
