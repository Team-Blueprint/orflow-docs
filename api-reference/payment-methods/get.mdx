---
title: "Get Payment Method"
openapi: "GET /v1/payment-methods/{payment_method_id}/get"
---

Retrieve a specific payment method by ID.

<CodeGroup>
```bash { title: "cURL" }
curl {{API_BASE_URL}}/v1/payment-methods/<payment_method_id>/get \
  -H "X-API-Key: sk_test_..." \
  -H "X-Project-ID: <project_id>"
```
</CodeGroup>

**Path Parameters:**

| Field | Type | Description |
|-------|------|-------------|
| `payment_method_id` | string (UUID) | Unique identifier of the payment method |

**Response:**
Returns a `PaymentMethodRead` object.

**Required Headers:**

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes |
