Webhooks let your application react to events in real-time — successful payments, failed charges, subscription changes, and more.

## Inbound Webhooks (Payment Provider Events)

Orflow receives events from payment providers (Nomba) and forwards them to your configured endpoints.

### Nomba Webhook Endpoint

Receive and verify Nomba webhook events:

```bash
POST /v1/webhooks/inbound/nomba
```

**Headers:**
| Header | Required | Description |
|--------|----------|-------------|
| `nomba-signature` | Yes | HMAC-SHA256 signature for verification |
| `nomba-timestamp` | Yes | Request timestamp for replay protection |
| `nomba-event-id` | No | Unique event ID for idempotency |

**Payload:**
```json
{
  "event_type": "charge.success",
  "requestId": "req_abc123",
  "data": {
    "merchant": { "userId": "mer_abc", "walletId": "wal_xyz" },
    "transaction": { "transactionId": "txn_123", "type": "charge", "time": "2024-01-15T10:30:00Z", "responseCode": "00" }
  }
}
```

<Note>
Configure your Nomba webhook URL in the Nomba dashboard: `https://api.orflow.io/v1/webhooks/inbound/nomba`
</Note>

## Outbound Webhooks (Your Endpoints)

Configure endpoints where Orflow sends events for your workspace.

### Create Webhook Endpoint

```bash
POST /v1/webhooks/endpoints/add
```

**Request:**
```json
{
  "url": "https://your-app.com/webhooks/orflow",
  "events": ["subscription.created", "subscription.canceled", "charge.success", "charge.failed"],
  "secret": "whsec_optional_secret_for_verification"
}
```

### List Webhook Endpoints

```bash
GET /v1/webhooks/endpoints/all
```

### Delete Webhook Endpoint

```bash
DELETE /v1/webhooks/endpoints/{endpoint_id}
```

## Event Catalog

List all available event types you can subscribe to:

```bash
GET /v1/webhooks/events/catalog
```

## Event Deliveries

View delivery history for a specific event:

```bash
GET /v1/webhooks/events/{event_id}/deliveries
```

## Event Types

| Category | Events |
|----------|--------|
| Subscription | `subscription.created`, `subscription.activated`, `subscription.trialing`, `subscription.canceled`, `subscription.paused`, `subscription.resumed`, `subscription.changed` |
| Payment | `charge.success`, `charge.failed`, `charge.refunded`, `charge.pending` |
| Customer | `customer.created`, `customer.updated`, `customer.deleted` |
| Payment Method | `payment_method.attached`, `payment_method.detached` |
| Invoice | `invoice.created`, `invoice.paid`, `invoice.failed` |

## Required Headers

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes |
| `X-Project-ID` | Yes (for outbound endpoints) |
