---
title: "Projects"
description: "Manage projects within your tenant workspace."
icon: "folder"
---

Projects provide logical separation within a tenant. Each project has its own API keys, plans, customers, and subscriptions.

## Create a Project

```bash
POST /v1/projects/create
```

**Request:**
```json
{
  "name": "Acme Corp Dashboard",
  "description": "Main dashboard project for Acme Corp"
}
```

## List Projects

```bash
GET /v1/projects/list
```

## Get a Project

```bash
GET /v1/projects/{project_id}
```

## Update a Project

```bash
PATCH /v1/projects/{project_id}/update
```

**Request:**
```json
{
  "name": "Updated Project Name",
  "description": "Updated description"
}
```

## Delete a Project

```bash
DELETE /v1/projects/{project_id}/del
```

<Warning>
Deleting a project permanently removes all its plans, customers, subscriptions, and webhooks.
</Warning>

## Required Headers

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes (tenant-level) |
