---
title: "Get Audit Log"
openapi: "GET /v1/subscriptions/{subscription_id}/audit-log"
---

Returns the full history of state transitions for a subscription, newest first.

<CodeGroup>
```bash { title: "cURL" }
curl {{API_BASE_URL}}/v1/subscriptions/<subscription_id>/audit-log \
  -H "X-API-Key: sk_test_..." \
  -H "X-Project-ID: <project_id>"
```
</CodeGroup>

**Path Parameters:**

| Field | Type | Description |
|-------|------|-------------|
| `subscription_id` | string (UUID) | Unique identifier of the subscription |

**Response:**

```json
[
  {
    "id": "...",
    "entity_id": "...",
    "old_status": "active",
    "new_status": "canceled",
    "reason": null,
    "actor": "system",
    "created_at": "2024-01-20T15:00:00Z"
  }
]
```

**Required Headers:**

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes |
