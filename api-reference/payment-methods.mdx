Payment methods represent tokenized payment instruments (cards, bank accounts) stored for recurring billing.

## Create a Payment Method

Register a new payment method for a customer:

```bash
POST /v1/payment-methods/create
```

**Request:**
```json
{
  "customer_id": "uuid",
  "type": "card",
  "token": "tok_visa",
  "set_default": true
}
```

<Note>
The `token` should come from your payment provider's client-side SDK (e.g., Stripe's PaymentMethod token, Nomba's card token).
</Note>

## List Customer Payment Methods

List all payment methods for a specific customer:

```bash
GET /v1/payment-methods/customer/{customer_id}
```

## Get a Payment Method

Retrieve a specific payment method by ID:

```bash
GET /v1/payment-methods/{payment_method_id}/get
```

## Update a Payment Method

Partially update a payment method's details:

```bash
PATCH /v1/payment-methods/{payment_method_id}/update
```

**Request:**
```json
{
  "metadata": { "source": "updated_via_api" }
}
```

## Set Default Payment Method

Mark a payment method as the default for its customer:

```bash
POST /v1/payment-methods/{payment_method_id}/set-default
```

## Delete a Payment Method

Permanently delete a payment method:

```bash
DELETE /v1/payment-methods/{payment_method_id}/del
```

<Warning>
If this was the customer's default payment method, the next most recent payment method will become the default.
</Warning>
