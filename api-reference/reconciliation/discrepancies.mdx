---
title: "List Discrepancies"
openapi: "GET /v1/reconciliation/discrepancies"
---

Returns paginated reconciliation discrepancies. Tenants see only their own; platform API keys see all.

**Query Parameters:**

| Field | Type | Description |
|-------|------|-------------|
| `run_id` | UUID | Filter by reconciliation run |
| `tenant_id` | UUID | Filter by tenant (platform keys only) |
| `discrepancy_type` | enum | `missing_in_orflow`, `missing_in_provider`, `amount_mismatch`, `status_mismatch` |
| `resolved` | boolean | Filter by resolution status |
| `date_from` | ISO8601 | Filter by min created date |
| `date_to` | ISO8601 | Filter by max created date |
| `page` | integer | Page number. Default: `1` |
| `per_page` | integer | Items per page. Default: `20`, max: `100` |

      "our_amount": 10000,

**Required Headers:**

| Header | Required |
|--------|----------|
| `X-API-Key` | Yes |
