## Base URL

All API requests use a single base URL:

```
{{ API_BASE_URL }}
```

## API Keys

Orflow provides four API key slots per tenant. The key prefix determines both the key type and which payment environment is used.

| Key | Prefix | Visibility | Environment | Use Case |
|-----|--------|------------|-------------|----------|
| Public Test | `pk_test_...` | Publishable | Sandbox | Client-side SDK, development |
| Secret Test | `sk_test_...` | Secret | Sandbox | Server-side, development |
| Public Live | `pk_live_...` | Publishable | Live | Client-side SDK, production |
| Secret Live | `sk_live_...` | Secret | Live | Server-side, production |

**Test keys** route payment operations to the sandbox Nomba gateway.  
**Live keys** route to the live Nomba gateway.

<Warning>
Never use live API keys in development. Never commit secret keys to version control.
</Warning>

## Making API Calls

```bash
# Sandbox (testing)
curl -H "X-API-Key: sk_test_..." \
     -H "X-Project-ID: your_project_uuid" \
     {{ API_BASE_URL }}/v1/plans/list

# Live (production)
curl -H "X-API-Key: sk_live_..." \
     -H "X-Project-ID: your_project_uuid" \
     {{ API_BASE_URL }}/v1/plans/list
```

## Environment Variables

Store keys securely in your environment:

```bash
# .env.local (sandbox)
ORFLOW_API_KEY=sk_test_abc123...
ORFLOW_PROJECT_ID=proj_abc123...
ORFLOW_BASE_URL={{ API_BASE_URL }}

# Production environment
ORFLOW_API_KEY=sk_live_xyz789...
ORFLOW_PROJECT_ID=proj_xyz789...
```

<Warning>
Use separate `.env` files per environment. Never commit them to git.
</Warning>
