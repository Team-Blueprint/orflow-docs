Orflow uses a two-level hierarchy to organize your billing resources.

## Hierarchy

```
Tenant (Organization)
└── Project A
    ├── Plans
    ├── Customers
    ├── Subscriptions
    ├── Payment Methods
    └── Webhooks
└── Project B
    └── ...
```

## Tenant

A **Tenant** represents your organization or company. It is the top-level container that holds:

- **Authentication**: Your login credentials, JWT tokens
- **API Keys**: Four key slots (pk_test, sk_test, pk_live, sk_live)
- **Projects**: One or more projects
- **Team Members**: Users with access to the dashboard

## Project

A **Project** is a logical workspace within a tenant. Each project has isolated:

- **Plans**: Pricing tiers specific to this project
- **Customers**: Customer records and their data
- **Subscriptions**: Active and historical subscriptions
- **Payment Methods**: Tokenized payment instruments
- **Webhooks**: Outbound webhook endpoints and delivery logs
- **API Keys**: The project inherits the tenant's API keys (scoped via `X-Project-ID` header)

## Managing Projects

Projects are created and managed in the **Orflow Dashboard** — there is no API for project CRUD. Use the dashboard to:

- **Create** a project via the onboarding flow or the + New Project button
- **Switch** between projects using the **Project Selector** in the sidebar
- **View** your project ID and API keys in **Project Settings**

## API Key Scoping

| Key Type | Scope | Use Case |
|----------|-------|----------|
| `pk_test` / `sk_test` | Tenant-wide | Sandbox testing |
| `pk_live` / `sk_live` | Tenant-wide | Production |

All API requests require the `X-API-Key` header. Project-scoped endpoints (plans, customers, subscriptions, webhooks) additionally require `X-Project-ID` to scope the request to a specific project.

## When to Use Multiple Projects

- **Multiple products/brands** under one company
- **Different teams** needing separate billing data
- **Different environments** (staging vs production) — though Sandbox/Live handles this too
- **Client work** — each client gets their own project
